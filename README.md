# Student-Academic-Performance-in-Public-Schools
Investigating the relationship between various socioeconomic factors and student academic performance in public schools. The dataset contains comprehensive information on 2,392 high school students, detailing their demographics, study habits, parental involvement, extracurricular activities, and academic performance.
